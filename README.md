# ♛ RajaChess

### Multiplayer Chess • 2 to 4 Players • Smart AI • Gamified Experience

**RajaChess** is a feature-rich, gamified web-based chess application built from scratch using **HTML5, CSS3, and modern JavaScript (ES6+)**.

Unlike traditional chess, RajaChess supports **2-player, 3-player, and 4-player battle modes**, along with custom AI opponents, a virtual in-game economy, player analytics, achievements, themes, piece customization, synthesized sound effects, and much more.

## 🎮 Play RajaChess

🔗 **Live Demo:** [Play RajaChess Live] https://multiplayer-chess-eta.vercel.app/

> Jump into a 2P, 3P, or 4P chess battle and experience chess in a completely different way.

## ✨ Features

### ♟️ Multi-Player Battlefield

* **2-Player Mode** for classic chess battles
* **3-Player Mode** for chaotic multi-king gameplay
* **4-Player Mode** for the ultimate chess battle
* Play with local friends
* Configurable game modes and board setup

### 🤖 Smart Multi-King AI Engine

RajaChess includes a custom-built AI system designed for multi-king chess positions.

* 3 AI difficulty levels:

  * Basic
  * Intermediate
  * Advanced
* Custom position evaluation
* Multi-king position analysis
* Anti-loop/endgame handling
* AI opponents for different game modes

### 👑 "Shahi Khazana" Virtual Economy

A built-in points and rewards system makes every match more engaging.

* Earn **Gold Coins** by winning matches
* Store system powered by `localStorage`
* Unlock exclusive:

  * ♟️ Board Themes
  * 🎨 Piece Skins
  * 🔷 Custom Piece Shapes
* Persistent player progress

### 📊 Player Analytics & Achievement Badges

Track your performance through a real-time statistics dashboard.

* Matches Played
* Win Rate
* Player Statistics
* Achievement System
* Unlockable badges such as:

  * 🏆 First Victory
  * 👑 Grand Monarch
  * 💰 Treasury Tycoon

### 🔊 Synthesized Audio Engine

RajaChess uses the **Web Audio API** to generate game sounds dynamically.

* Move sounds
* Capture sounds
* Check sounds
* Victory sounds
* No external audio files required
* Live sound/mute controls

### 🎨 Customization

Make your chess experience your own.

* Multiple board themes
* Custom piece skins
* Custom piece shapes
* Unlockable visual content
* Gamified UI experience

### ⚡ Lightweight & Fast

RajaChess is built using pure web technologies.

* HTML5
* CSS3
* Modern ES6+ JavaScript
* No heavy external frameworks
* Lightweight architecture
* Fast browser execution
